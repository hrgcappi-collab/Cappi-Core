# Cappi Core

Телеграм-бот сети Cappi (Одесса): цены, показатели, KPI, производство,
зоны доставки. Python на стандартной библиотеке, без зависимостей — это
осознанное решение: бот должен запускаться где угодно и переживать
обновления окружения.

## Что делает

| модуль | о чём |
|---|---|
| 💰 Цены | найти позицию, сменить цену приказом, проверить, доехала ли она до сайта и Glovo |
| 🛒 Продажи | стоп-лист, акции, отмены, списания, заказы в работе |
| 📈 Показатели | итоги дня, план, время доставки, жалобы, зоны |
| 🧑‍🍳 Персонал | смена, KPI кухни, процент кухни, тайный гость, правки явок |
| 🏭 Производство | себестоимость, просчёт по составу, новое блюдо (карточка → техкарта → цена) |
| 🤖 Джамшут | зоны доставки и непогода: Core управляет, Джамшут о Core не знает |
| ⚙️ Настройки | своя точка, блоки итогов дня, какие тревоги получать |

Сам, без спроса: итоги дня в 22:30, сверка цен раз в сутки, слежение за
стоп-листом и списаниями, запрос тайного гостя 3-го числа и правок часов
2-го, контроль компенсации за непогоду.

## Где что

    bot.py            экраны, кнопки, приём сообщений, сторожа
    cappi.py          доступ к Syrve: сессии, приказы, цены, номенклатура
    report.py         показатели дня, выручка по ПиУ, явки, времена
    kpi.py            KPI шефа и су-шефов, процент кухни
    cost.py           себестоимость по техкартам и остаткам
    nomenclature.py   словарь: «рис» → «Рис на суши (готовый) ПФ»
    access.py         роли и права          bugs.py      журнал сбоев
    настройки.py      настройки на человека jamshut.py   клиент бота зон
    stoplist.py promo.py webhook.py healthcheck.py выгрузка.py
    tests/            хаос, отказы, краш, права, данные, скорость
    selftest.py       все экраны + требования ТЗ (callback_data, длина, тупики)

## Запуск

    cp api.env.example ~/.cappi/api.env && chmod 600 ~/.cappi/api.env
    # заполнить доступы
    python3 healthcheck.py     # проверить, что всё отвечает
    python3 bot.py

Выкат на сервер — `deploy/README.md`.

## Перед коммитом

    python3 selftest.py        # обязателен: красный — коммита нет
    python3 tests/хаос.py      # мусор и обрыв сети через путь обработки
    python3 tests/права.py     # роль без права ничего не пишет
    python3 tests/данные.py    # цифры против Syrve

Правила, оплаченные ошибками, — в `CLAUDE.md`. Читать до правок.
