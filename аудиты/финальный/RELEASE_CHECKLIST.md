# Чек-лист выкатки Cappi Core

## Перед выкаткой
- [ ] `python3 selftest.py` — зелёный, ни одного экрана дольше 30 с.
- [ ] `python3 tests/непонятые.py`, `tests/права.py` — зелёные.
- [ ] Локальный `bot.py` не запущен (`pgrep -f "Cappi-Core/bot.py"` пуст).
- [ ] `git status` чист, коммит с описанием «зачем», не «что».
- [ ] Если менялся `api.env.example` — ключи добавлены в `data/api.env` на сервере.
- [ ] Копия `data/` сделана (`tar` в `~/backup/`), пока F-04 не закрыт.

## Выкатка
- [ ] `rsync` без `data/`, `docker compose up -d --build`.
- [ ] `docker ps` — ровно один `cappi-core`, статус Up.
- [ ] `docker logs cappi-core --tail 5` — «бот запущен», приёмник на 8787, без traceback.

## Сразу после
- [ ] В личке: «⚡ сейчас», «🩺 здоровье», «🔌 проверка связи» — отвечают.
- [ ] Свободная фраза («сколько продали вчера») — экран, не «Не понял».
- [ ] Кнопка из старого сообщения (любая inline) — не «HTTP 400».
- [ ] Если выкатка после 22:00 — убедиться, что итоги дня не ушли второй раз.
- [ ] Через сутки: `bugs.jsonl` — нет новых «сбой», ночные итоги пришли в 22:30.

## Откат
- `git checkout <прошлый коммит>` локально → тот же rsync + up. Меньше двух минут.
- Состояние в `data/` откату не подлежит — оно совместимо между версиями;
  если менялся формат файла, откат только вместе с копией `data/`.
